CSS Units

CSS supports different units for sizing and spacing.

  • px — pixels
  • % — percentage
  • em — relative to the element's font size
  • rem — relative to the root font size
  • vh — viewport height
  • vw — viewport width

CSS Comments

CSS comments are written using the following syntax: 

/* This is a CSS comment */

Comments help explain code but are not displayed as webpage content.

Cascade, Specificity and Inheritance

CSS follows rules that determine which styles are applied when multiple rules target the same element.

Specificity helps determine which selector has greater priority, while inheritance allows some properties to pass from parent elements to their children.
