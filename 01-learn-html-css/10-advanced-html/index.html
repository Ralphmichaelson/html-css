HTML Media

Audio

The audio element can be used to add sound to a webpage.

Video

The video element allows video content to be displayed directly on a webpage.

Metadata

Metadata provides information about a webpage that is not normally displayed as visible page content.

This page uses metadata such as character encoding, viewport information, description, and author information. 

<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<meta name="description" content="...">
<meta name="author" content="...">

HTML Best Practices

  • Use a proper HTML document structure.
  • Use semantic elements whenever appropriate.
  • Use meaningful and descriptive headings.
  • Add useful alternative text to meaningful images.
  • Connect form labels with their inputs.
  • Keep HTML properly nested and indented.
  • Use descriptive link text.
  • Use CSS for presentation instead of outdated HTML presentation attributes.
  • Validate your HTML and fix errors.
  • Keep your HTML simple, readable, and meaningful.

Embedding External Content

An iframe can be used to embed another webpage or external resource inside a webpage.

HTML Validation

Validating HTML helps identify structural and syntax errors in a webpage.

A useful practice is to check your HTML with an HTML validator after completing a project.
